Guide

This site has two modes.

  • ✏️ Solve mode — the same format as the real TOEFL. The passage is on the left and one question at a time is on the right; answer it to move on to the next. The elapsed time counts up in the header. Clicking words is disabled in this mode.
  • 📖 Study mode — every word in the text is clickable. For listed words, the right panel shows an English explanation (etymology, definition, role in the passage, related words), and you can add the word to Anki on the spot. For unlisted words, it shows a link to the Cambridge Dictionary. The "Question explanations" tab shows whether each answer was correct, with an explanation in English.

You can also read in study mode without solving the questions. Results (score and time) are saved only in your browser (localStorage) and are never sent to a server.

Setting up Anki

The "+ Add to Anki" button in study mode adds a word card directly to Anki on your computer. This setup is needed once.

  1. Install Anki (desktop version).
  2. In Anki, open "Tools → Add-ons → Get Add-ons", enter the code 2055492159 and install AnkiConnect.
  3. Open "Tools → Add-ons → AnkiConnect → Config" and add this site's URL (https://shutouyusei.github.io) to webCorsOriginList. You can copy and paste this as is: 
    {
    "webCorsOriginList": [
        "http://localhost",
        "https://shutouyusei.github.io"
    ]
}
    (Leave the other settings unchanged and keep any existing values. Enter the URL above exactly as written, not your own user name.)
  4. Restart Anki.
  5. In study mode, click a word and press "+ Add to Anki". If "✅ Added to deck" appears, setup is complete. Cards go into the deck "TOEFL Reading" (you can change the deck name with the ⚙ button).

The URL must match exactly, including the port number. If you fork this repository and run it on your own GitHub Pages, or open it from a local development server (such as http://localhost:8000), add that URL in the same format. http://localhost:8000 is treated as a different URL from http://localhost: 

"webCorsOriginList": ["http://localhost", "http://localhost:8000"]

Troubleshooting

  • "Could not connect to Anki" appears — check that Anki is running. If it is, the next item is the likely cause.
  • Anki is running but the connection fails — check that webCorsOriginList above contains the URL of the page you have open (including the port number). Restart Anki after changing the setting.
  • Another program is using port 8765 — AnkiConnect uses port 8765. If another program, such as a development server, already holds this port, AnkiConnect cannot listen on it even when Anki is running, and the connection fails. Run lsof -nP -iTCP:8765 -sTCP:LISTEN in a terminal and quit any program other than Anki that it lists.
  • "Anki returned an error" appears — the actual error from Anki is shown. If it is model was not found: Basic, your Anki has no note type named "Basic" (non-English versions of Anki use a translated name). In that case, create a note type named "Basic" in Anki.
  • It does not work in Safari — Safari blocks requests from an HTTPS page to your own computer (http://127.0.0.1) as mixed content. To use Anki from the public site, use Chrome or Firefox.

Limitation: this feature works only while Anki is running on your computer. It cannot add cards directly to a phone (AnkiDroid / AnkiMobile). Add the cards to desktop Anki, then use Anki's sync to bring them to your phone.
