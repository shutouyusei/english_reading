使い方

このサイトには2つのモードがあります。

  • ✏️ 解答モード — 本番のTOEFLと同じ形式です。左にパッセージ、右に問題が1問ずつ表示され、回答するごとに次の問題へ進みます。経過時間はヘッダーでカウントアップ表示されます。このモードでは単語クリックは無効です。
  • 📖 解説モード — 本文中のすべての単語をクリックできます。収録語は語源・定義・文中での役割・関連語の日本語解説が右パネルに表示され、その場でAnkiに追加できます。未収録語はWeblioへのリンクが表示されます。「問題の解説」タブでは各問題の正誤と日本語解説を確認できます。

問題を解かずに解説モードだけで読むこともできます。成績(スコア・所要時間)はお使いのブラウザ内(localStorage)にのみ保存され、サーバーには送信されません。

Anki連携のセットアップ

解説モードの「＋ Ankiに追加」ボタンで、単語カードをPCのAnkiに直接追加できます。初回のみ以下の設定が必要です。

  1. Anki(PC版)をインストールする。
  2. Ankiのメニュー「ツール → アドオン → 新規アドオンを取得」でコード 2055492159 を入力し、AnkiConnect をインストールする。
  3. 「ツール → アドオン → AnkiConnect → 設定」を開き、webCorsOriginList にこのサイトのURL(https://shutouyusei.github.io)を追加する。下をそのままコピーして貼り付けてください: 
    {
    "webCorsOriginList": [
        "http://localhost",
        "https://shutouyusei.github.io"
    ]
}
    (他の設定項目は変更不要。既存の値は残したまま追記してください。ここに入れるのはご自身のユーザー名ではなく、上記のURLそのままです)
  4. Ankiを再起動する。
  5. 解説モードで単語をクリック →「＋ Ankiに追加」を押し、「✅ 追加しました」と出れば完了。カードはデッキ「TOEFL Reading」に入ります(デッキ名は ⚙ ボタンで変更可)。

ポート番号まで含めて完全一致で判定されます。 このリポジトリをフォークして自分のGitHub Pagesで動かす場合や、手元の開発サーバー(http://localhost:8000 など)で開く場合は、そのURLを同じ形式で追加してください。http://localhost:8000 は http://localhost とは別のURLとして扱われます: 

"webCorsOriginList": ["http://localhost", "http://localhost:8000"]

うまくいかないときは

  • 「Ankiに接続できませんでした」と出る — Ankiが起動しているか確認してください。起動していれば、次の項目が原因である可能性が高いです。
  • Ankiは起動しているのに接続できない — 上記の webCorsOriginList に、いま開いているページのURL(ポート番号を含む)が入っているか確認してください。設定変更後はAnkiの再起動が必要です。
  • ポート8765を他のプログラムが使っていないか — AnkiConnectはポート8765を使います。他の開発用サーバーなどがこのポートを先に占有していると、Ankiを起動してもAnkiConnectが待ち受けできず、接続に失敗します。ターミナルで lsof -nP -iTCP:8765 -sTCP:LISTEN を実行し、Anki以外のプログラムが出てきたらそれを終了してください。
  • 「Ankiがエラーを返しました」と出る — Ankiからの実際のエラー内容が表示されます。model was not found: Basic の場合、お使いのAnkiのノートタイプ名が「Basic」ではありません(日本語版では「基本」など)。その場合はAnki側で「Basic」という名前のノートタイプを用意してください。
  • Safariで動かない — SafariはHTTPSページからローカル(http://127.0.0.1)への通信を混在コンテンツとして遮断します。公開版のサイトでAnki連携を使う場合はChromeまたはFirefoxをお使いください。

制約: この機能はPCでAnkiを起動している間のみ動作します。スマートフォン(AnkiDroid / AnkiMobile)への直接追加はできません。PCのAnkiに追加後、Ankiの同期機能でスマートフォンへ反映してください。
