使い方

このサイトには2つのモードがあります。

  • ✏️ 解答モード — 本番のTOEFLと同じ形式です。左にパッセージ、右に問題が1問ずつ表示され、回答するごとに次の問題へ進みます。経過時間はヘッダーでカウントアップ表示されます。このモードでは単語クリックは無効です。
  • 📖 解説モード — 本文中のすべての単語をクリックできます。収録語は語源・定義・文中での役割・関連語の日本語解説が右パネルに表示され、その場でAnkiに追加できます。未収録語はWeblioへのリンクが表示されます。「問題の解説」タブでは各問題の正誤と日本語解説を確認できます。

問題を解かずに解説モードだけで読むこともできます。成績(スコア・所要時間)はお使いのブラウザ内(localStorage)にのみ保存され、サーバーには送信されません。

Anki連携のセットアップ

解説モードの「＋ Ankiに追加」ボタンで、単語カードをPCのAnkiに直接追加できます。初回のみ以下の設定が必要です。

  1. Anki(PC版)をインストールする。
  2. Ankiのメニュー「ツール → アドオン → 新規アドオンを取得」でコード 2055492159 を入力し、AnkiConnect をインストールする。
  3. 「ツール → アドオン → AnkiConnect → 設定」を開き、webCorsOriginList にこのサイトのURLを追加する: 
    {
    "webCorsOriginList": [
        "http://localhost",
        "https://あなたのユーザー名.github.io"
    ]
}
    (他の設定項目は変更不要。既存の値は残したまま追記してください)
  4. Ankiを再起動する。
  5. 解説モードで単語をクリック →「＋ Ankiに追加」を押し、「✅ 追加しました」と出れば完了。カードはデッキ「TOEFL Reading」に入ります(デッキ名は ⚙ ボタンで変更可)。

制約: この機能はPCでAnkiを起動している間のみ動作します。スマートフォン(AnkiDroid / AnkiMobile)への直接追加はできません。PCのAnkiに追加後、Ankiの同期機能でスマートフォンへ反映してください。
